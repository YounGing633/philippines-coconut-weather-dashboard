# 网页输出设计说明

本包面向菲律宾椰子 / Copra / CNO 供给端天气监测。重点不是堆表，而是快速判断：主产区过去是否缺雨、未来能否补回来、是否可能转化为椰子供应风险。

## 页面模块

1. 左侧结论：一句话判断总体天气风险。
2. 右侧核心指标：近 14 / 30 / 90 天可切换。
3. 交互地图：点击产区后查看历史与未来。
4. 主产区窗口指标：可筛选、可下载 CSV、点击行联动地图。
5. PAGASA 官方观点：按时间顺序展示核心信息和源文件链接。

## Dry 级别口径

地图和筛选中的 Dry 级别是市场监测口径，参考 PAGASA 的降雨占常年区间：

- Normal：累计降雨 ≥ 80% Normal
- Dry Condition：累计降雨为 60%–80% Normal
- Dry Spell：累计降雨为 40%–60% Normal
- Drought：累计降雨 < 40% Normal

PAGASA正式干旱认定还涉及连续月份条件，本看板的窗口判断用于日度跟踪和提前预警，不等同于官方正式名单。
